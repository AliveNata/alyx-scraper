Overview

AlyxLabs Scraper adalah multi-platform web scraper yang memungkinkan Anda mengumpulkan data dari berbagai sumber secara langsung (direct scraping). Dibangun dengan Flask backend dan modern responsive UI.

AlyxLabs Scraper is a multi-platform web scraper that collects data from several sources directly. It runs on a Flask backend with a responsive UI.

Fitur Utama

Main Features

  • 8 Sumber Terkurasi - Google News, News Sites, GDELT, YouTube, Wikipedia, OpenAlex, Semantic Scholar, Kaskus
  • Teks Lengkap Artikel - Ambil isi artikel penuh (bukan cuma cuplikan) untuk analisis konten
  • Filter Tanggal & Dedup - Rentang tanggal untuk sumber historis, hasil duplikat dibuang otomatis
  • Catatan Koleksi & Sitasi - Metadata pengumpulan (keyword, sumber, waktu WIB) siap untuk bab Metodologi
  • Analisis - Frekuensi kata terbanyak dan distribusi waktu
  • Export - CSV, JSON, XLSX, atau Markdown (dengan metadata)
  • Bilingual & Light/Dark - Indonesia/English, tema terang sebagai default
  • Admin Dashboard - Toggle platform, kunci API, audit log (tersembunyi)
  • 8 Curated Sources - Google News, News Sites, GDELT, YouTube, Wikipedia, OpenAlex, Semantic Scholar, Kaskus
  • Full Article Text - Fetch full article bodies (not just snippets) for content analysis
  • Date Filter & Dedup - Date range for historical sources, duplicates removed automatically
  • Collection Record & Citation - Provenance metadata (keyword, sources, time) ready for a methodology section
  • Analysis - Top-term frequency and timeline distribution
  • Export - CSV, JSON, XLSX, or Markdown (with metadata)
  • Bilingual & Light/Dark - Indonesian/English, light theme by default
  • Admin Dashboard - Platform toggle, API keys, audit log (hidden)

Tech Stack

  • Flask - Python web framework
  • BeautifulSoup4 - HTML/XML parsing
  • Requests - HTTP library
  • Pandas - Data manipulation & export
  • SQLite - Audit logging database
  • Chart.js - Admin dashboard charts
  • Bootstrap 5 - UI framework

Platform

AlyxLabs mengumpulkan data dari 8 sumber terkurasi berikut. Yang butuh API key gratis bisa dinyalakan/dimatikan admin.

AlyxLabs collects from these 8 curated sources. Those needing a free API key can be toggled by the admin.

Google News

Berita terbaru via Google News RSS. Reliable, tanpa API key.

Latest news via Google News RSS. Reliable, no API key.

News Sites

Portal berita Indonesia + dunia (Detik, Kompas, Liputan6, CNN, BBC) via RSS. Reliable.

Indonesian + global news portals (Detik, Kompas, Liputan6, CNN, BBC) via RSS. Reliable.

GDELT

Indeks berita global (DOC 2.0 API) dengan cakupan historis. Rate-limit 1 request/5 detik.

Global news index (DOC 2.0 API) with historical coverage. Rate limit 1 request/5s.

YouTube

Cari video via YouTube Data API v3. Butuh API key gratis (set di Admin).

Video search via YouTube Data API v3. Needs a free API key (set in Admin).

Wikipedia

Cari artikel referensi via MediaWiki API (id.wikipedia). Reliable, tanpa key.

Reference articles via the MediaWiki API (id.wikipedia). Reliable, no key.

OpenAlex

Jurnal & paper akademik (judul, penulis, tahun, abstrak, DOI). Cakupan jurnal Indonesia bagus, tanpa key.

Academic journals & papers (title, authors, year, abstract, DOI). Good Indonesian journal coverage, no key.

Semantic Scholar

Paper akademik via Semantic Scholar API. Butuh API key gratis agar stabil (set di Admin).

Academic papers via the Semantic Scholar API. Needs a free API key to be stable (set in Admin).

Kaskus

Thread & diskusi dari Kaskus.co.id via indeks pencarian. Kadang flaky.

Threads & discussions from Kaskus.co.id via search indexing. Occasionally flaky.

Image Scraper

Fitur Image Scraper memungkinkan Anda mencari dan mengumpulkan gambar dari web dengan 3 cara:

The Image Scraper lets you find and collect images from the web in 3 ways:

1. Pencarian Gambar

1. Image Search

Masukkan kata kunci untuk mencari gambar dari web. Hasil ditampilkan dalam grid yang bisa diklik untuk melihat detail dan mencari gambar yang mirip.

Enter a keyword to search for images from the web. Results show in a grid you can click to see details and find similar images.

2. Scrape dari URL

2. Scrape from a URL

Masukkan URL halaman web untuk mengekstrak semua gambar di halaman tersebut. Mendukung tag <img>, og:image, dan data-src (lazy loading).

Enter a web page URL to extract every image on that page. Supports <img> tags, og:image, and data-src (lazy loading).

3. Upload & Cari

3. Upload & Search

Upload gambar dari komputer Anda (JPG, PNG, GIF, WebP). Dengan Google Vision API aktif, sistem mencari gambar yang mirip; tanpa itu, sistem mencari berdasarkan nama file. Mendukung drag & drop.

Upload an image from your computer (JPG, PNG, GIF, WebP). With the Google Vision API enabled it finds visually similar images; without it, it searches by the file name. Supports drag and drop.

Export

Pilih format lewat dropdown lalu klik tombol download. Tersedia 4 format:

Pick a format from the dropdown then click the download button. Four formats:

  • CSV - Comma-separated values (metadata koleksi ada di baris komentar #), cocok untuk spreadsheet dan analisis
  • JSON - Struktur { metadata, data }, cocok untuk integrasi/pemrograman
  • XLSX - Excel dengan sheet Metadata + sheet Hasil terpisah
  • Markdown - Dokumen rapi berisi metadata + tiap hasil (termasuk teks lengkap), enak dibaca
  • CSV - Comma-separated values (collection metadata in leading # comment lines), good for spreadsheets and analysis
  • JSON - A { metadata, data } structure, good for integration/programming
  • XLSX - Excel with a separate Metadata sheet + Hasil sheet
  • Markdown - A readable document with metadata + each result (including full text)

Kolom data: Platform, Judul, Konten, Teks Lengkap, URL, Tanggal, Sumber, Keyword, Lokasi. Setiap export juga membawa Catatan Koleksi (keyword, sumber, waktu WIB, total) untuk keperluan metodologi.

Data columns: Platform, Title, Content, Full Text, URL, Date, Source, Keyword, Location. Every export also carries the Collection Record (keyword, sources, WIB time, total) for methodology use.
