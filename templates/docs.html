Overview

Alyx Scraper adalah multi-platform web scraper yang memungkinkan Anda mengumpulkan data dari berbagai sumber secara langsung (direct scraping). Dibangun dengan Flask backend dan modern responsive UI.

Fitur Utama

  • Direct Scraping - Scrape langsung dari platform tanpa perantara API pihak ketiga
  • 9 Platform - Google News, News Sites, Reddit, Kaskus, X/Twitter, Facebook, Threads, Quora, Instagram
  • Image Scraper - Cari gambar, scrape dari URL, upload untuk mencari gambar mirip
  • Export - Download hasil dalam format CSV, JSON, atau XLSX
  • Bilingual - Bahasa Indonesia dan English
  • Light/Dark Theme - Theme toggle dengan light sebagai default
  • Admin Dashboard - Monitoring penggunaan dan audit log (tersembunyi)

Tech Stack

  • Flask - Python web framework
  • BeautifulSoup4 - HTML/XML parsing
  • Requests - HTTP library
  • Pandas - Data manipulation & export
  • SQLite - Audit logging database
  • Chart.js - Admin dashboard charts
  • Bootstrap 5 - UI framework

Platform

Alyx mendukung scraping langsung dari 9 platform berikut:

Google News

Scrape berita terbaru via Google News RSS feed. Mendukung pencarian berdasarkan keyword dan lokasi.

News Sites

Scrape dari portal berita worldwide termasuk Indonesia (Detik, Kompas, Liputan6, CNN, BBC, Reuters).

Reddit

Direct scraping via Reddit JSON API. Mengambil post, subreddit, dan content secara langsung.

Kaskus

Scrape langsung dari Kaskus.co.id - forum terbesar di Indonesia. Cari thread dan diskusi.

X / Twitter

Scraping via Nitter instances atau library twikit. Mendukung pencarian tweet terbaru.

Facebook

Direct scraping menggunakan facebook-scraper library. Scrape post dari halaman publik.

Threads

Scrape konten dari Threads (Meta). Mengambil post dan diskusi berdasarkan keyword.

Quora

Scrape pertanyaan dan jawaban dari Quora. Cocok untuk riset topik dan Q&A.

Instagram

Scrape post publik dari Instagram berdasarkan keyword pencarian.

Image Scraper

Fitur Image Scraper memungkinkan Anda mencari dan mengumpulkan gambar dari web dengan 3 cara:

1. Pencarian Gambar

Masukkan kata kunci untuk mencari gambar dari web. Hasil akan ditampilkan dalam grid yang bisa diklik untuk melihat detail dan mencari gambar yang mirip.

2. Scrape dari URL

Masukkan URL halaman web untuk mengekstrak semua gambar yang ada di halaman tersebut. Mendukung tag <img>, og:image, dan data-src (lazy loading).

3. Upload & Cari Mirip

Upload gambar dari komputer Anda (JPG, PNG, GIF, WebP) untuk mencari gambar yang mirip atau terkait. Mendukung drag & drop.

Fitur Tambahan

  • Related Image Search - Klik gambar hasil, lalu klik "Cari Mirip" untuk mencari gambar serupa
  • Grid View - Tampilan grid responsif dengan preview
  • Modal Preview - Klik gambar untuk melihat ukuran penuh

Export

Hasil scraping bisa di-download dalam 3 format:

  • CSV - Comma-separated values, cocok untuk spreadsheet dan analisis data
  • JSON - JavaScript Object Notation, cocok untuk integrasi dengan aplikasi lain
  • XLSX - Microsoft Excel format, cocok untuk laporan dan presentasi

Setiap file export berisi kolom: Platform, Judul, Konten, URL, Tanggal, Sumber, Keyword, dan Lokasi.
