Overview

Alyx Scraper adalah multi-platform web scraper yang memungkinkan Anda mengumpulkan data dari berbagai sumber secara langsung (direct scraping). Dibangun dengan Flask backend dan modern responsive UI.

Alyx Scraper is a multi-platform web scraper that collects data from several sources directly. It runs on a Flask backend with a responsive UI.

Fitur Utama

Main Features

  • Direct Scraping - Scrape langsung dari platform tanpa perantara API pihak ketiga
  • 9 Platform - Google News, News Sites, Reddit, Kaskus, X/Twitter, Facebook, Threads, Quora, Instagram
  • Image Scraper - Cari gambar, scrape dari URL, upload untuk mencari gambar mirip
  • Export - Download hasil dalam format CSV, JSON, atau XLSX
  • Bilingual - Bahasa Indonesia dan English
  • Light/Dark Theme - Theme toggle dengan light sebagai default
  • Admin Dashboard - Monitoring penggunaan dan audit log (tersembunyi)
  • Direct Scraping - Scrape straight from each platform, no third-party API in between
  • 9 Platforms - Google News, News Sites, Reddit, Kaskus, X/Twitter, Facebook, Threads, Quora, Instagram
  • Image Scraper - Search images, scrape from a URL, upload to find similar images
  • Export - Download results as CSV, JSON, or XLSX
  • Bilingual - Indonesian and English
  • Light/Dark Theme - Theme toggle, light by default
  • Admin Dashboard - Usage monitoring and audit log (hidden)

Tech Stack

  • Flask - Python web framework
  • BeautifulSoup4 - HTML/XML parsing
  • Requests - HTTP library
  • Pandas - Data manipulation & export
  • SQLite - Audit logging database
  • Chart.js - Admin dashboard charts
  • Bootstrap 5 - UI framework

Platform

Alyx mendukung scraping langsung dari 9 platform berikut:

Alyx scrapes directly from these 9 platforms:

Google News

Scrape berita terbaru via Google News RSS feed. Mendukung pencarian berdasarkan keyword dan lokasi.

Scrape the latest news via the Google News RSS feed. Search by keyword and location.

News Sites

Scrape dari portal berita worldwide termasuk Indonesia (Detik, Kompas, Liputan6, CNN, BBC, Reuters).

Scrape news portals worldwide including Indonesia (Detik, Kompas, Liputan6, CNN, BBC, Reuters).

Reddit

Scraping via Reddit API resmi (OAuth). Mengambil post, subreddit, dan konten secara langsung.

Scraping via the official Reddit API (OAuth). Pulls posts, subreddits, and content directly.

Kaskus

Scrape langsung dari Kaskus.co.id, forum terbesar di Indonesia. Cari thread dan diskusi.

Scrape straight from Kaskus.co.id, the largest forum in Indonesia. Find threads and discussions.

X / Twitter

Scraping via Nitter instances atau library twikit. Mendukung pencarian tweet terbaru.

Scraping via Nitter instances or the twikit library. Searches recent tweets.

Facebook

Direct scraping menggunakan library facebook-scraper. Scrape post dari halaman publik.

Direct scraping with the facebook-scraper library. Scrapes posts from public pages.

Threads

Scrape konten dari Threads (Meta). Mengambil post dan diskusi berdasarkan keyword.

Scrape content from Threads (Meta). Pulls posts and discussions by keyword.

Quora

Scrape pertanyaan dan jawaban dari Quora. Cocok untuk riset topik dan Q&A.

Scrape questions and answers from Quora. Good for topic research and Q&A.

Instagram

Scrape post publik dari Instagram berdasarkan keyword pencarian.

Scrape public posts from Instagram by search keyword.

Image Scraper

Fitur Image Scraper memungkinkan Anda mencari dan mengumpulkan gambar dari web dengan 3 cara:

The Image Scraper lets you find and collect images from the web in 3 ways:

1. Pencarian Gambar

1. Image Search

Masukkan kata kunci untuk mencari gambar dari web. Hasil ditampilkan dalam grid yang bisa diklik untuk melihat detail dan mencari gambar yang mirip.

Enter a keyword to search for images from the web. Results show in a grid you can click to see details and find similar images.

2. Scrape dari URL

2. Scrape from a URL

Masukkan URL halaman web untuk mengekstrak semua gambar di halaman tersebut. Mendukung tag <img>, og:image, dan data-src (lazy loading).

Enter a web page URL to extract every image on that page. Supports <img> tags, og:image, and data-src (lazy loading).

3. Upload & Cari

3. Upload & Search

Upload gambar dari komputer Anda (JPG, PNG, GIF, WebP). Dengan Google Vision API aktif, sistem mencari gambar yang mirip; tanpa itu, sistem mencari berdasarkan nama file. Mendukung drag & drop.

Upload an image from your computer (JPG, PNG, GIF, WebP). With the Google Vision API enabled it finds visually similar images; without it, it searches by the file name. Supports drag and drop.

  • Grid View - Tampilan grid responsif dengan preview

  • Related Image Search - Click a result, then "Cari Mirip" to find similar images
  • Grid View - Responsive grid with previews

Export

Hasil scraping bisa di-download dalam 3 format:

Scraping results can be downloaded in 3 formats:

  • CSV - Comma-separated values, cocok untuk spreadsheet dan analisis data
  • JSON - JavaScript Object Notation, cocok untuk integrasi dengan aplikasi lain
  • XLSX - Microsoft Excel format, cocok untuk laporan dan presentasi
  • CSV - Comma-separated values, good for spreadsheets and data analysis
  • JSON - JavaScript Object Notation, good for integrating with other apps
  • XLSX - Microsoft Excel format, good for reports and presentations

Setiap file export berisi kolom: Platform, Judul, Konten, URL, Tanggal, Sumber, Keyword, dan Lokasi.

Each export file has these columns: Platform, Title, Content, URL, Date, Source, Keyword, and Location.
