Overview

AlyxLabs Scraper adalah multi-platform web scraper yang memungkinkan Anda mengumpulkan data dari berbagai sumber secara langsung (direct scraping). Dibangun dengan Flask backend dan modern responsive UI.

AlyxLabs Scraper is a multi-platform web scraper that collects data from several sources directly. It runs on a Flask backend with a responsive UI.

Image Scraper

Fitur Image Scraper memungkinkan Anda mencari dan mengumpulkan gambar dari web dengan 3 cara:

The Image Scraper lets you find and collect images from the web in 3 ways:

1. Pencarian Gambar

1. Image Search

Masukkan kata kunci untuk mencari gambar dari web menggunakan Bing (default) atau Google Images (tanpa API key). Mendukung pagination via parameter offset untuk menjelajahi lebih banyak hasil. Hasil ditampilkan dalam grid yang bisa diklik untuk melihat detail dan mencari gambar yang mirip.

Enter a keyword to search for images via Bing (default) or Google Images (no API key needed). Supports pagination via the offset parameter to browse further results. Results show in a grid you can click to see details and find similar images.

2. Scrape dari URL

2. Scrape from a URL

Masukkan URL halaman web untuk mengekstrak semua gambar di halaman tersebut. Mendukung tag <img>, og:image, dan data-src (lazy loading). Untuk halaman yang mengandalkan JavaScript (SPA, infinite scroll), gunakan mode JS rendering yang menjalankan Chromium headless secara otomatis.

Enter a web page URL to extract every image on that page. Supports <img> tags, og:image, and data-src (lazy loading). For JavaScript-heavy pages (SPAs, infinite scroll), use JS rendering mode which runs a headless Chromium browser automatically.

3. Upload & Cari

3. Upload & Search

Upload gambar dari komputer Anda (JPG, PNG, GIF, WebP). Sistem selalu mencoba TinEye terlebih dahulu (tanpa API key) untuk mendeteksi kecocokan. Jika Google Vision API dikonfigurasi, hasil akan diperkaya dengan gambar visual yang serupa. Mendukung drag & drop.

Upload an image from your computer (JPG, PNG, GIF, WebP). The system always tries TinEye first (no API key required) to detect matches. If a Google Vision API key is configured, results are enriched with visually similar images. Supports drag and drop.

Export

Pilih format lewat dropdown lalu klik tombol download. Tersedia 6 format:

Pick a format from the dropdown then click the download button. Six formats:

  • CSV - Comma-separated values (metadata koleksi ada di baris komentar #), cocok untuk spreadsheet dan analisis
  • JSON - Struktur { metadata, data }, cocok untuk integrasi/pemrograman
  • XLSX - Excel dengan sheet Metadata + sheet Hasil terpisah
  • Markdown - Dokumen rapi berisi metadata + tiap hasil (termasuk teks lengkap), enak dibaca
  • RIS - Format referensi standar (.ris), langsung import ke Mendeley, Zotero, EndNote
  • BibTeX - Format LaTeX (.bib), cocok untuk karya tulis ilmiah dan Overleaf
  • CSV - Comma-separated values (collection metadata in leading # comment lines), good for spreadsheets and analysis
  • JSON - A { metadata, data } structure, good for integration/programming
  • XLSX - Excel with a separate Metadata sheet + Hasil sheet
  • Markdown - A readable document with metadata + each result (including full text)
  • RIS - Standard reference format (.ris), import directly into Mendeley, Zotero, or EndNote
  • BibTeX - LaTeX format (.bib), good for academic writing and Overleaf

Kolom data: Platform, Judul, Konten, Teks Lengkap, URL, Tanggal, Sumber, Keyword, Lokasi. Setiap export juga membawa Catatan Koleksi (keyword, sumber, waktu WIB, total) untuk keperluan metodologi.

Data columns: Platform, Title, Content, Full Text, URL, Date, Source, Keyword, Location. Every export also carries the Collection Record (keyword, sources, WIB time, total) for methodology use.

Export per Platform

Per-Platform Export

Tiap platform punya tombol download sendiri di header grup hasilnya. Klik untuk download hanya hasil dari platform itu dalam format yang dipilih. Berguna saat ingin memisahkan data berita dari data akademik, misalnya.

Each platform has its own download button in its result group header. Click it to download only that platform's results in the selected format. Useful when you need to keep news data separate from academic data, for example.

Sitasi OtomatisAuto Citation

AlyxLabs menghasilkan sitasi siap pakai untuk setiap hasil scraping. Dua format didukung:

AlyxLabs generates ready-to-use citations for every scraped result. Two formats are supported:

APA 7

Format standar internasional (American Psychological Association edisi ke-7). Contoh:

International standard format (American Psychological Association 7th edition). Example:

Penulis, A. A. (Tahun, Bulan Tanggal). Judul artikel. Nama Sumber. URL

Mendikbud (Indonesia)

Format sitasi sesuai pedoman Kementerian Pendidikan, Kebudayaan, Riset, dan Teknologi RI. Digunakan untuk karya tulis ilmiah, skripsi, dan tesis.

Citation format per the Indonesian Ministry of Education, Culture, Research, and Technology guidelines. Used for academic papers, theses, and dissertations.

Penulis. (Tahun). Judul Artikel. Nama Sumber. Diakses dari URL

Klik ikon sitasi di samping tiap hasil untuk menyalin format yang diinginkan. Sitasi juga otomatis masuk ke export Markdown.

Click the citation icon next to any result to copy the format you want. Citations are also included automatically in Markdown exports.

NotifikasiNotifications

Terima ringkasan hasil scraping setelah proses selesai. Berguna untuk query yang berjalan lama atau supaya tidak perlu menunggu di depan browser.

Receive a result summary once scraping finishes. Useful for long-running queries or when you don't want to wait at the browser.

Email

Email

Masukkan alamat email di kolom "Notifikasi saat selesai" sebelum scraping. Ringkasan (keyword, total hasil per platform, waktu selesai) dikirim ke email tersebut setelah scraping selesai.

Enter an email address in the "Notify when done" field before scraping. A summary (keyword, total results per platform, finish time) is sent to that address once scraping is complete.

Webhook

Masukkan URL webhook (Slack Incoming Webhook, Discord, atau endpoint custom) di kolom yang tersedia. Payload dikirim dalam format JSON yang mudah diparse.

Enter a webhook URL (Slack Incoming Webhook, Discord, or a custom endpoint) in the provided field. The payload is sent as JSON and easy to parse.

Kedua kolom bersifat opsional dan independent - bisa diisi salah satu atau keduanya.

Both fields are optional and independent - you can fill in either or both.
