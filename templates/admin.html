Aktifkan twikit (login X/Twitter)
Jika ON, scraper pakai akun X/Twitter untuk hasil lebih banyak dan akurat. Jika OFF, pakai Nitter (tidak butuh login, tapi kadang down).
Login ke X / Twitter
Cara Ambil Auth Token dari Browser:
  1. Buka x.com di browser, pastikan sudah login
  2. Tekan F12 → tab Application (Chrome) atau Storage (Firefox)
  3. Klik Cookies → https://x.com
  4. Cari cookie bernama auth_token → salin Value-nya
  5. Cari juga cookie bernama ct0 → salin Value-nya
Twitter/X sering memblokir atau mengubah flow login. Gunakan Auth Token jika metode ini error.
Token/cookies hanya disimpan sebagai file lokal twitter_cookies.json — tidak dikirim ke server eksternal.
Instances dicoba satu per satu dari atas ke bawah sampai berhasil. Jika semua gagal, otomatis fallback ke Google Search site:x.com.
Email Configuration
Digunakan untuk kirim link Forgot Password ke email admin. Gunakan Gmail dengan App Password (myaccount.google.com/apppasswords).
Cara buat App Password: Google Account → Security → 2-Step Verification → App Passwords → buat baru untuk "Mail".

Login dengan akun Instagram untuk mendapatkan hasil lebih banyak dari hashtag publik. Disarankan pakai akun dummy/alternatif, bukan akun utama.
Cara Ambil Session ID:
  1. Buka instagram.com di browser, pastikan sudah login
  2. Tekan F12 → tab Application (Chrome) atau Storage (Firefox)
  3. Klik Cookies → https://www.instagram.com
  4. Cari cookie bernama sessionid → salin Value-nya
Instagram sering memblokir login otomatis via script. Gunakan Session ID jika metode ini gagal.
Session ID/Password hanya dipakai untuk generate session file lokal — tidak dikirim ke server eksternal manapun.
