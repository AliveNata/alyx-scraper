Email Configuration
Digunakan untuk kirim link Forgot Password ke email admin. Gunakan Gmail atau SMTP hosting. Untuk Gmail buat App Password di myaccount.google.com/apppasswords.
Gmail: smtp.gmail.com:465. cPanel hosting: mail.domain.com:465 (SSL) atau :587 (TLS)
Cara buat App Password Gmail: Google Account → Security → 2-Step Verification → App Passwords → buat baru untuk "Mail".
